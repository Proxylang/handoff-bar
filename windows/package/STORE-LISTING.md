## Description

Claude Code keeps a cache of each chat so replies stay fast and cheap. Leave a chat alone too long and the cache expires: the next message makes Claude re-read the whole chat at full price.

HandoffBar saves a short summary of each chat, called a handoff, a few minutes before its cache expires. Click the HandoffBar icon in the taskbar corner, click the chat, and paste the handoff into a new Claude Code chat to keep going.

A handoff holds the chat's title, folder and git branch, your first and last ten requests, the choices you made, the next steps Claude listed, commands left running, files changed, and Claude's last reply.

Works with Claude Code in the terminal, the VS Code extension, and the Claude desktop app. Your chats never leave your PC: no account, no analytics, no AI model. HandoffBar is open source (MIT).

HandoffBar is not affiliated with Anthropic.
