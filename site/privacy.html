HandoffBar privacy policy

Last updated October 7, 2026. Applies to HandoffBar for Mac and Windows.

Your chats stay on your computer

HandoffBar reads the chat files Claude Code saves in the .claude/projects folder in your home folder, and writes handoff files to .claude/handoffs. It never sends your chats, your handoffs, or anything about you to us or anyone else. There is no account, no analytics, no tracking, and no AI model.

The one network request

The version downloaded from GitHub checks once a day for a newer version. It asks GitHub's public API for the latest release number of HandoffBar. The request carries no data from your computer. Like any web request, it reaches GitHub from your internet address; see GitHub's privacy statement. The Microsoft Store version does not make this request, because the Store handles updates.

Clipboard

HandoffBar puts text on your clipboard only when you click a chat in its panel.

Contact

HandoffBar is made by Proxylang. Questions: open an issue on GitHub.
