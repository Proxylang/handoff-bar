Pick up any Claude Code chat where you left off (without wasting tokens)

Before a chat's cache expires, HandoffBar saves a summary. Paste it into a new chat and keep going, instead of paying to reload the old one.

Download for Mac View source

Why it exists

Claude Code caches each chat so replies stay fast and cheap. Leave a chat alone too long and the cache expires. The next message re-reads the whole chat at full price. A fresh chat with a short handoff is cheaper and quicker.

It watches

Once a minute it checks your Claude Code chats and reads how long each one's cache lasts: 5 minutes or 1 hour.

It writes

A few minutes before a cache runs out, it saves that chat's handoff to ~/.claude/handoffs.

You paste

Click the hand in your menu bar, click the chat, and paste the handoff into a new Claude Code chat.

What a handoff holds

Plain Markdown, one file per chat. Enough for the new chat to know what you were doing, without the full history.

  • TitleThe name you gave the tab, or Claude's own title.
  • WhereWorking folder, git branch, and the old chat file.
  • Your requestsThe first one, plus the last ten.
  • Your choicesWhen Claude asked you to pick, the question, the options, and your answer.
  • Next stepsThe to-do list Claude left at the end of the chat.
  • Running thingsDev servers and other commands Claude started in the background.
  • Last errorIf something failed in the final few steps.
  • Changed filesEvery file the chat edited.
  • Last replyClaude's final answer in the old chat.

Features

Search every chat

Type to filter by title, project, or chat id. Search covers every saved handoff.

Your tab names

Chats show the name you gave the tab, even if you rename it after the handoff was saved.

Easy to scan

Chats are grouped by day, with the project and how long ago. Hover one to see your last request.

Open at login

One checkbox keeps it running after a restart. Light and dark mode follow your Mac.

Terminal, VS Code, desktop

Works with Claude Code in the terminal, the VS Code extension, and the Code tab of the Claude desktop app.

Any recent Mac

macOS 13 or later, Apple Silicon or Intel. Want Windows? Tell us.

Security

Your chats stay on your Mac. HandoffBar never sends your chats, handoffs, or anything about you anywhere: no account, no analytics, no AI model.

What it reads

The chat files Claude Code already saves in ~/.claude/projects. Nothing else on your Mac.

What it writes

One Markdown file per chat in ~/.claude/handoffs. The clipboard only changes when you click a chat.

How it's built

A native Swift app (SwiftUI and AppKit), about 780 lines, with no third-party code.

One network request

Once a day it asks GitHub for the latest version number, so it can show an update button. That request carries no data from your Mac.

Signed and open

Signed with a Developer ID and notarized by Apple. MIT licensed: read every line or build it yourself on GitHub.
