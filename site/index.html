Before a chat's cache expires, HandoffBar saves a summary. Paste it into a new chat and keep going, instead of paying to reload the old one.

Why it exists

Claude Code caches each chat so replies stay fast and cheap. Leave a chat alone too long and the cache expires. The next message re-reads the whole chat at full price. A fresh chat with a short handoff is cheaper and quicker.

It watches

Once a minute it checks your Claude Code chats and reads how long each one's cache lasts: 5 minutes or 1 hour.

It writes

A few minutes before a cache runs out, it saves that chat's handoff to ~/.claude/handoffs.

You paste

Click the hand in your Mac menu bar or Windows taskbar, click the chat, and paste the handoff into a new Claude Code chat.

Pick where you want the button

Three ways to copy a handoff. They all save the same file for each chat, so you can use more than one. None of them types into your chat.

Inside Claude Code in the terminal

A Copy handoff button above the prompt, a cache countdown under it, and a warning when the cache runs out.

Works with Claude Code in the terminal. Type this at its prompt:

/plugin install handoffbar --marketplace Proxylang/handoff-bar

The Claude desktop app can't show buttons from extensions or mods yet. Use the menu bar app there.

What a handoff holds

Plain Markdown, one file per chat. Enough for the new chat to know what you were doing, without the full history.

  • TitleThe name you gave the tab, or Claude's own title.
  • WhereWorking folder, git branch, and the old chat file.
  • Your requestsThe first one, plus the last ten.
  • Your choicesWhen Claude asked you to pick, the question, the options, and your answer.
  • Next stepsThe to-do list Claude left at the end of the chat.
  • Running thingsDev servers and other commands Claude started in the background.
  • Last errorIf something failed in the final few steps.
  • Changed filesEvery file the chat edited.
  • Last replyClaude's final answer in the old chat.

Features

Search every chat

Type to filter by title, project, or chat id. Search covers every saved handoff.

Your tab names

Chats show the name you gave the tab, even if you rename it after the handoff was saved.

Easy to scan

Chats are grouped by day, with the project and how long ago. Hover one to see your last request.

Open at login

One checkbox keeps it running after a restart. Light and dark mode follow your system setting.

Terminal, VS Code, desktop

Works with Claude Code in the terminal, the VS Code extension, and the Code tab of the Claude desktop app.

Mac and Windows

macOS 13 or later, Apple Silicon or Intel. Windows 10 (version 1809) or later, from the Microsoft Store.

Security

Your chats stay on your computer. HandoffBar never sends your chats, handoffs, or anything about you anywhere: no account, no analytics, no AI model.

What it reads

The chat files Claude Code already saves in ~/.claude/projects. Nothing else on your computer.

What it writes

One Markdown file per chat in ~/.claude/handoffs. The clipboard only changes when you click a chat or the Copy handoff button.

How it's built

The Mac app is native Swift (SwiftUI and AppKit), about 780 lines. The Windows app is C# (WinForms), about 1,100 lines. The Claude Code mod is TypeScript, about 580 lines. The VS Code extension adds about 170 lines on top of the mod's handoff writer. Neither makes network requests, and none of them uses third-party code.

One network request

Once a day the Mac app asks GitHub for the latest version number, so it can show an update button. That request carries no data from your Mac. The Windows app makes no requests at all; the Microsoft Store handles its updates.

Signed and open

The Mac app is signed with a Developer ID and notarized by Apple. The Windows app is signed by the Microsoft Store. MIT licensed: read every line or build it yourself on GitHub.
